## 1. 与原研究计划的关系

本文件是一份新研究计划，不修改、不覆盖旧版 `research-plan.md`。旧版计划继续作为历史规划记录和长期研究方向参考，但不再直接指导实验实施。

本项目后续采用以下三级管理关系：

1. **研究计划 V2**：规定阶段五及后续研究的总体方向、先后顺序和实验治理原则。
2. **经过用户批准的阶段规格（spec）**：规定某一阶段允许修改的变量、实验矩阵、指标、停止条件和验收门，是该阶段的最高执行依据。
3. **旧版 research plan**：仅保留为原始设想、论文选题和长期创新点来源；与V2或已批准spec冲突时，不作为执行依据。

因此，研究计划V2批准后，后续实验按照V2安排阶段；进入具体阶段时，还必须先获得该阶段spec的明确批准。

## 2. 研究背景

本项目研究基于全乳钼靶影像的良恶性分类，核心方法为CNN与Transformer混合架构。当前已经在CBIS-DDSM钙化子集上完成严格、无患者泄漏的端到端基线，包括患者级数据划分、模型实现、正式训练、仅验证集阈值选择和一次官方测试集评估。

旧材料中记录的ROC AUC `0.7869`、PR AUC `0.6673`和敏感度`80.6%`属于历史参考结果，不是本次严格复现实际取得的指标。

## 3. 已验证的严格基线

### 3.1 数据方案

- 数据集：CBIS-DDSM钙化子集。
- 输入单位：whole mammogram全乳影像。
- CC和MLO视图作为独立样本。
- 训练集：986张影像、482名患者。
- 验证集：241张影像、120名患者。
- 官方测试集：284张影像、151名患者。
- train/validation/test患者交集均为0。
- DICOM成功解码：1,511 / 1,511。

### 3.2 模型架构

- 输入尺寸：`256 × 256`。
- ImageNet预训练EfficientNet-B0。
- 使用`1 × 1`卷积将1,280通道投影至`D=512`。
- 生成64个空间token并加入二维正弦位置编码。
- 四层Transformer Encoder、八个注意力头、FFN宽度2,048。
- token均值聚合、LayerNorm和单logit输出。
- 可训练参数：17,274,493。

### 3.3 正式实验结果

| 指标 | 本次严格复现 | 历史参考 |
|---|---:|---:|
| ROC AUC | 0.7414 | 0.7869 |
| PR AUC | 0.6729 | 0.6673 |
| Sensitivity | 70.59% | 80.60% |
| Specificity | 63.64% | 未报告 |
| Accuracy | 66.55% | 未报告 |
| F1 | 0.6388 | 未报告 |

验证集冻结阈值为`0.04822634`。测试集混淆矩阵为TN=105、FP=60、FN=35、TP=84。

## 4. 基线暴露出的主要问题

### 4.1 微钙化细节损失

当前流程将整张全乳影像直接缩放到`256 × 256`。原始影像包含大量黑色背景，直接缩放既浪费有效像素，也可能压缩微小钙化点和局部组织结构。

### 4.2 过拟合明显

训练损失下降至`0.1581`，验证损失上升至`2.7057`；验证ROC AUC长期停留在约`0.66`。这说明模型已经学到有效排序信号，但泛化能力和训练稳定性仍有明显改进空间。

### 4.3 概率校准偏移

本次验证阈值明显低于历史参考阈值`0.4515`，说明当前模型logit和概率校准状态与历史实验差异较大。后续应优先比较ROC AUC、PR AUC等阈值无关指标，并单独研究校准问题。

### 4.4 样本口径不完全一致

历史结果使用326条测试异常记录，本项目按唯一whole mammogram影像形成284个测试样本。两者不是完全相同的评价总体，因此不能把指标差异简单归因于模型结构。

## 5. 修订后的近期研究目标

阶段五已经在不改变EfficientNet-B0 + Transformer架构的前提下，完成确定性乳房区域预处理、输入分辨率和安全增强消融。最终候选为`384 × 384`、乳房crop+letterbox、无随机增强；三个随机种子的validation ROC AUC均值为`0.684684`，样本标准差为`0.014927`。

后续目标是在该候选上建立可归因的架构升级证据链：

> 先在EfficientNet-B0上分别验证BiFPN多尺度融合与CBAM注意力的贡献，再单独评估切换至EfficientNet-V2S的影响，最终形成EfficientNet-V2S + BiFPN + CBAM核心模型。

EfficientNet-V2S、BiFPN和CBAM不得在第一次架构实验中同时引入。每次初筛只改变一个主要变量或使用已完成消融确认的组合，避免无法判断性能变化来自哪个组件。

## 6. 分阶段研究路线

### 阶段五：乳房区域预处理与分辨率消融

- 状态：Gate A至Gate D已完成。
- 去除非乳房黑色背景，同时保留完整乳房。
- 使用等比例缩放和padding，避免解剖结构被直接拉伸。
- 在模型结构固定时比较`256`、`384`、`512`输入。
- 评估一组预先声明的钼靶安全增强策略。
- 只根据验证集ROC AUC和PR AUC选择候选方案。
- 不运行官方测试集推理。
- 最终候选固定为`384 × 384`、乳房crop+letterbox、无随机增强，作为阶段六及阶段七的统一输入与预处理起点。

### 阶段六：EfficientNet-B0上的BiFPN与CBAM模块消融

阶段六统一完成所有以EfficientNet-B0为backbone的结构模块实验，保持阶段五的Transformer、训练协议、`384 × 384`输入和预处理不变。按照以下顺序实施：

1. `EfficientNet-B0 + Transformer`：直接引用阶段五冻结候选，不重新训练。
2. `EfficientNet-B0 + BiFPN + Transformer`：从B0提取P2-P5特征，单独评估BiFPN多尺度融合贡献。
3. `EfficientNet-B0 + CBAM + Transformer`：相对阶段五候选，单独评估CBAM贡献。
4. `EfficientNet-B0 + BiFPN + CBAM + Transformer`：使用已经冻结的BiFPN和CBAM配置，评估两个模块是否互补。

BiFPN实验必须实现统一通道宽度的双向融合，并在高分辨率下限制Transformer token数量，避免注意力显存失控。BiFPN重复次数、CBAM插入位置和通道压缩比例必须在阶段六spec中预先声明，不允许根据validation结果持续扩展搜索空间。

阶段六只回答BiFPN和CBAM在B0骨干上的独立贡献与组合效果，不更换backbone，也不把B0上的结论自动视为已经适用于EfficientNet-V2S。

### 阶段七：EfficientNet-V2S升级、模块迁移与最终核心模型

阶段七只处理backbone切换和已验证模块向V2S迁移，按照以下顺序实施：

1. `EfficientNet-V2S + Transformer`：保持384输入、预处理和训练选择规则不变，单独评估从B0切换到V2S的backbone贡献。
2. `EfficientNet-V2S + BiFPN + Transformer`：把阶段六冻结的多尺度方案迁移到V2S，验证BiFPN在新骨干上的增量贡献。
3. `EfficientNet-V2S + CBAM + Transformer`：在不包含BiFPN时独立迁移阶段六冻结CBAM，形成完整的V2S二因素消融。
4. `EfficientNet-V2S + BiFPN + CBAM + Transformer`：组合阶段六冻结的BiFPN和CBAM方案，测量模块交互并形成导师要求的最终核心方法。

阶段七应引用阶段五和阶段六已经完成的B0对照，不重复训练相同的B0配置。V2S不是B0的原位参数替换；迁移前必须重新声明V2S的P2-P5端点与通道形状，并完成参数量、token数量、显存和预训练权重加载审计。

最终报告必须区分：

- **规定的核心方法**：EfficientNet-V2S + BiFPN + CBAM；
- **验证集经验最佳模型**：严格按照预先声明的validation ROC AUC规则选出的配置。

如果规定的核心方法没有超过某个B0消融模型，仍须如实报告两者，不得通过查看官方测试结果改变模型选择或隐去负结果。

阶段七现已完成。三seed validation ROC AUC结果为：

- P7-E01 V2S：`0.6968069874 ± 0.0252671825`，成为validation经验最佳模型；
- P7-E04 V2S + BiFPN + CBAM：`0.6684445399 ± 0.0144141602`，仍保留为规定核心方法；
- 阶段五P5-E02对照：`0.6846840397 ± 0.0149272049`。

这说明V2S独立backbone升级在三seed均值上优于阶段五对照，而冻结BiFPN/CBAM迁移没有提升V2S候选。该结论只使用train/validation，未读取官方test。

### 阶段八：可解释性与外部验证

- 从最终卷积层或融合层生成Grad-CAM++热力图。
- 官方ROI mask只作为解释性评价标注，不作为分类输入。
- 预先声明热力图阈值规则，报告IoU、Dice和病灶命中率。
- 模型冻结后再使用INbreast进行外部验证。
- 完成标签口径统一后，再考虑VinDr-Mammo。

### 长期扩展

- CC/MLO多视图融合。
- 分类与分割多任务学习。
- VinDr-Mammo、RSNA等更大规模外部数据集。
- 概率校准、公平性和跨域鲁棒性分析。

## 7. 实验治理原则

官方测试集结果已经在阶段四中产生。后续实验必须遵守：

- 预处理、架构、超参数和checkpoint选择期间禁止读取官方测试集。
- 不允许每完成一个实验就查看一次测试指标。
- 固定当前患者划分和manifest哈希，保证直接可比。
- 每个阶段必须先有书面spec，再实施代码和训练。
- BiFPN、CBAM和backbone切换应先分别消融，再评估组合，不允许在首次实验中同时引入三个变量。
- 每次运行必须使用唯一实验ID和禁止覆盖的输出目录。
- 初筛使用固定随机种子，最终候选方案进行多随机种子确认。
- 负结果、失败实验和OOM记录不得静默删除。
- 每个最终结果记录代码commit、配置、seed、manifest哈希和checkpoint哈希。
- 规定的最终核心方法与validation经验最佳模型可以不同，报告中必须并列说明其定义和结果。
- 任何后续官方测试评估都必须说明：方法是在未参考该次测试输出的情况下选定，但这已经不是“首次未触碰测试集”的评估。

## 9. 预期研究贡献

后续研究的贡献不应只是堆叠更大的网络，而应形成一条受控证据链：分别说明全乳预处理、输入分辨率、BiFPN多尺度融合、CBAM注意力和EfficientNet-V2S backbone切换对钙化分类的实际贡献，并确保所有结论来自患者级安全、可审计的实验协议。

该路线最终以EfficientNet-V2S + BiFPN + CBAM为规定核心方法，同时保留validation经验最佳模型作为独立、诚实的实验结论，可为“多尺度注意力增强CNN-Transformer乳腺钼靶分类与可解释性研究”提供可信基线、完整消融证据和论文方法基础。
